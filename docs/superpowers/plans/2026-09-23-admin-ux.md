# Úpravy administrace (UX dozora) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Administrace jako úvodní stránka bez Dashboardu a s viditelnou
registrací; výpis her s akcemi; stanoviště s volitelným názvem, českými
typy, editací pod řádkem, bezpečným mazáním a plnou správou obrázků při
opětovné editaci.

**Architecture:** Backend: redirecty Breeze na `admin.games.index`,
sloupec `locations.name`, `LocationRequest`/`LocationController` rozšířené
o zachovávání stávajících obrázků (`existing_images[]`) a úklid
nepoužitých souborů, `GameController::edit` posílá stanoviště jako
explicitní pole s URL obrázků. Frontend: sdílené čisté helpery
(`taskTypes.js`, `imageSelection.js`, Vitest), znovupoužitelný
`ConfirmDialog.vue` (Breeze `Modal`), přepracované `LocationList`,
`LocationForm`, `TaskContentFields`, `Games/Index`.
Spec: `docs/superpowers/specs/2026-09-23-admin-ux-design.md`.

**Tech Stack:** Laravel 13 (FormRequest `after()`), Pest, Inertia + Vue 3,
Vitest (jen čisté funkce), Tailwind, Breeze komponenty (`Modal`,
`DangerButton`, `SecondaryButton`).

## Global Constraints

- Admin UI je česky. Hráčské UI se **nemění** (název stanoviště se dítěti
  nikdy neukazuje).
- Popisek stanoviště: `#{pozice} {name || "Stanoviště {pozice}"}`, kde
  pozice = 1-based index v seřazeném seznamu (`Game::locations()` řadí
  podle `order`, `id`).
- Typy česky: `arrival_only` → "Jen dojít", `pick_image` → "Vybrat
  obrázek", `photo_of_something` → "Vyfotit něco",
  `selfie_doing_something` → "Vyfotit se při činnosti" — jen z
  `resources/js/lib/taskTypes.js`.
- Stavy hry česky: `draft` → "koncept", `published` → "publikováno",
  `archived` → "archivováno".
- `pick_image`: celkem **3–6** obrázků (`existing_images` + nové
  `images`); `correct_index` indexuje **spojený** seznam `existing_images
  ++ images`; `existing_images` smí obsahovat jen cesty z aktuálního
  `task_payload.images` **tohoto** stanoviště.
- Soubory nepoužité po úspěšném uložení (odebrané/nahrazené obrázky,
  obrázky předchozího typu) a soubory smazaného stanoviště se mažou z disku
  `public`. Fotky hráčů (`attempt-photos/`) se nikdy nemažou.
- Každé mazání (hra, stanoviště) jde přes potvrzovací dialog.
- Routy s víc modely v URL zůstávají v `Route::scopeBindings()`; každá
  admin akce autorizuje přes `GamePolicy`.
- Testy: `php artisan test` a `npm run test:unit` musí na konci každého
  tasku projít; `npm run build` bez chyb.

function updateLocation($test, array $data)

test('keeping all existing images without uploading anything preserves them', function () {
    updateLocation($this, [
        'task_type' => 'pick_image',
        'existing_images' => ['task-images/a.jpg', 'task-images/b.jpg', 'task-images/c.jpg'],

    $payload = $this->location->fresh()->task_payload;
    expect($payload['images'])->toBe(['task-images/a.jpg', 'task-images/b.jpg', 'task-images/c.jpg'])

    private function buildTaskPayload(LocationRequest $request, ?Location $location): ?array
    {
        return match (TaskType::from($request->validated('task_type'))) {
            TaskType::ArrivalOnly => null,

// When an image is removed from the combined list, keep the "correct"
// radio pointing at the same image (or clear it if that image went away).
export function correctIndexAfterRemoval(correctIndex, removedIndex) {
    if (correctIndex === null || correctIndex === undefined) return null;
    if (correctIndex === removedIndex) return null;

    return correctIndex > removedIndex ? correctIndex - 1 : correctIndex;
}

    game: Object,
    locations: Array,
});

const editingId = ref(null);
const isAdding = ref(false);
const draggedId = ref(null);
const pendingDelete = ref(null); // { location, position }

const formOpen = computed(() => editingId.value !== null || isAdding.value);

const deleteWarning = computed(() =>
    props.game.status === 'published'
        ? 'Hráči, kteří už toto stanoviště plní, přijdou o svůj průběh na něm.'
        : null,
);

const onDragStart = (location) => { draggedId.value = location.id; };
const onDrop = (targetLocation) => {
    const ids = props.locations.map((l) => l.id);
    const from = ids.indexOf(draggedId.value);
    const to = ids.indexOf(targetLocation.id);
    ids.splice(to, 0, ids.splice(from, 1)[0]);

    router.patch(route('admin.games.locations.reorder', props.game.id), { order: ids }, { preserveScroll: true });
};

const closeForm = () => {
    editingId.value = null;
    isAdding.value = false;
};

const editLocation = (location) => {
    isAdding.value = false;
    editingId.value = location.id;
};

const startAdding = () => {
    editingId.value = null;
    isAdding.value = true;
};

const confirmDelete = () => {
    const { location } = pendingDelete.value;
    if (editingId.value === location.id) closeForm();

    router.delete(route('admin.games.locations.destroy', [props.game.id, location.id]), {
        preserveScroll: true,
        onFinish: () => {
            pendingDelete.value = null;
        },
    });
};
</script>

<template>
    <div class="space-y-4">
        <ul class="divide-y rounded border bg-white">
            <li
                v-for="(location, index) in locations"
                :key="location.id"
                :draggable="!formOpen"
                @dragstart="onDragStart(location)"
                @dragover.prevent
                @drop="onDrop(location)"
            >
                <div
                    class="flex items-center justify-between gap-4 p-3"
                    :class="editingId === location.id ? 'border-l-4 border-indigo-500 bg-indigo-50' : ''"
                >
                    <span class="font-medium text-gray-900">
                        {{ locationLabel(location, index + 1) }}
                        <span class="font-normal text-gray-500">· {{ taskTypeLabel(location.task_type) }}</span>
                    </span>
                    <div class="flex items-center gap-8">
                        <button
                            v-if="editingId !== location.id"
                            type="button"
                            class="text-indigo-600"
                            @click="editLocation(location)"
                        >Upravit</button>
                        <button
                            type="button"
                            class="text-sm text-red-400 hover:text-red-600"
                            @click="pendingDelete = { location, position: index + 1 }"
                        >Smazat</button>
                    </div>
                </div>

                <div v-if="editingId === location.id" class="border-l-4 border-indigo-500 bg-indigo-50/40 p-3">
                    <LocationForm
                        :key="location.id"
                        :game="game"
                        :location="location"
                        :heading="`Upravuješ: ${locationLabel(location, index + 1)}`"
                        @saved="closeForm"
                        @cancel="closeForm"
                    />
                </div>
            </li>
            <li v-if="locations.length === 0" class="p-3 text-gray-500">Zatím žádná stanoviště.</li>
        </ul>

        <button v-if="!formOpen" type="button" class="rounded bg-indigo-600 px-4 py-2 text-white" @click="startAdding">
            Přidat stanoviště
        </button>

        <LocationForm v-if="isAdding" :game="game" heading="Nové stanoviště" @saved="closeForm" @cancel="closeForm" />

        <ConfirmDialog
            :show="pendingDelete !== null"
            :message="pendingDelete ? `Smazat stanoviště ${locationLabel(pendingDelete.location, pendingDelete.position)}? Tato akce je nevratná.` : ''"
            :warning="deleteWarning"
            @confirm="confirmDelete"
            @cancel="pendingDelete = null"
        />
    </div>
</template>
